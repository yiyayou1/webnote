如何配置你的 Supabase

WebNote 使用你自己的 Supabase 项目存储数据，全程免费，数据完全属于你。按以下步骤操作，约需 5 分钟。

1注册 Supabase 账号
打开 supabase.com，点击 Start your project，用 GitHub 或邮箱免费注册。
无需绑定信用卡，免费版足够个人使用（500MB 数据库）。
2创建新项目
登录后点击 New Project，填写：
· 项目名称（随意，如 webnote）
· 数据库密码（记住，以后可能用到）
· 地域（选离你最近的）

点击 Create new project，等待约 1 分钟初始化完成。
3建立数据库表
进入项目后，点击左侧菜单的 SQL Editor，把下方 SQL 完整粘贴进去，点击 Run 执行。 
-- 高亮表
CREATE TABLE highlights (
  id text PRIMARY KEY,
  user_id uuid REFERENCES auth.users ON DELETE CASCADE,
  url text, title text, text text, color text,
  mark_type text, annotation jsonb, sticky jsonb,
  start_xpath text, start_text_node_index int,
  start_offset int, end_xpath text,
  end_text_node_index int, end_offset int,
  anchor_text text, timestamp bigint,
  updated_at timestamptz DEFAULT now()
);

-- 笔记表
CREATE TABLE notes (
  id text PRIMARY KEY,
  user_id uuid REFERENCES auth.users ON DELETE CASCADE,
  content text, url text, title text,
  source text, comment text, timestamp bigint,
  updated_at timestamptz DEFAULT now()
);

-- 别名表
CREATE TABLE aliases (
  user_id uuid REFERENCES auth.users ON DELETE CASCADE,
  key text, alias text,
  PRIMARY KEY (user_id, key)
);

-- 开启行级安全（每个用户只能访问自己的数据）
ALTER TABLE highlights ENABLE ROW LEVEL SECURITY;
ALTER TABLE notes ENABLE ROW LEVEL SECURITY;
ALTER TABLE aliases ENABLE ROW LEVEL SECURITY;

-- 安全策略
CREATE POLICY "own" ON highlights FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "own" ON notes FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "own" ON aliases FOR ALL USING (auth.uid() = user_id);
4关闭邮箱验证（重要）
Supabase 默认要求注册时验证邮箱，但验证邮件里的链接会跳转失败。建议关闭：

· 进入 Authentication → Providers → Email
· 找到 Confirm email 开关，将其关闭
· 点击 Save 保存

关闭后用户注册时不需要验证邮箱，可以直接登录使用。
5获取 API 密钥
在项目页面，点击左侧菜单 Settings → API，找到并复制：

· Project URL（形如 https://xxxx.supabase.co）
· anon public key（eyJhbGci 开头的长字符串）

⚠️ 只复制 anon key，不要复制 service_role key，anon key 对用户安全。
6填入 WebNote
回到 WebNote 插件，把复制的 Project URL 和 anon key 填入连接设置，点击「连接并登录」。

注册一个新的 WebNote 账号（邮箱+密码），登录后数据会自动同步到你的 Supabase 项目。
7配置邮件跳转地址
在 Supabase 后台进入 Authentication → URL Configuration，填写以下两个地址：

Site URL：
https://yiyayout1.github.io/webnote Redirect URLs（点 Add URL 添加）：
https://yiyayout1.github.io/webnote/reset.html
这两个地址是 WebNote 统一提供的重置密码页面，所有用户共用，你的数据仍然只存在你自己的 Supabase 项目里。
